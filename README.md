## Summary

In this lab we learned how edge sensitive flip flops only capture signals when the clock signals transitions from low to high. And we also learned how to use a jk flip flop to implement a t flip flop. 

## Lab Questions

### What is difference between edge and level sensitive circuits?
Level sensitive curcuits follow inputs continuesly whenver an enable signal is high whereas edge sensitive flip flops capture inputs the moment the clock signal transitions.

### Why is it important to declare initial state?
It is important because it ensures the flipflop powers up with predictable starting values.

### What do edge sensitive circuits let us build?
They allow us to build clocked sequential circuits like flip flops.
